# GreenPath Ghana

AI-powered climate education and climate action platform for African youth.

**Learn → Improve → Take Action → Earn Rewards → Help the Planet**

## Stack

- Expo (React Native)
- NativeWind (Tailwind)
- Plus Jakarta Sans
- Reanimated

## Run

```bash
cd greenui
npm install
npx expo start
```

## Screens

Splash, Onboarding, Auth, Interests, Home, Lessons, Lesson Detail, AI Quiz, Quiz Results, Missions, Mission Detail, AI Verification, Voice Assistant, Rewards, Leaderboard, Community, Profile, Notifications, Analytics, Settings.
